# MoodyBot - Telegram Bot

MoodyBot is a Telegram bot that uses OpenAI's GPT-4o model to provide personality-based responses with the style of Hank Moody and Anthony Bourdain. It's flirty, emotionally intelligent, and brutally honest.

## Features

- Interact with a bot that has the combined personality of Hank Moody and Anthony Bourdain
- Get witty, sarcastic, and honest responses
- Maintains conversation history for context
- Simple command interface

## Commands

- `/start` - Reset the conversation and start fresh
- `/help` - Show help information
- `/forget` - Erase conversation history

## Requirements

- Python 3.x
- python-telegram-bot (v20.6)
- OpenAI Python SDK (v0.28)
- python-dotenv

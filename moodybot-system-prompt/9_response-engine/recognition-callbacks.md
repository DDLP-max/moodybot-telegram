# Recognition Callback (special case)

Recognition Callback is **one possible ending** — not the default.
Recognition Landing tools (Signature Line / Callback) are optional and OFF by default.

The preferred outcome is **BODY_ENDS_RESPONSE** when the body already landed.
Question Is the Exception — only when clarification is needed or authorial language earns return.
Signature Line is rare. See `signature-line.md` and `insight-first.md`.

## When Callback wins

Only when the user authored unusually distinctive language:

- "What got stretched out?"
- "I'm still carrying this."
- "It cracked something."
- "The room changed."

Those deserve rhetorical return.
Normal topic nouns do not.

## Selection order (only one wins)

1. BODY_ENDS_RESPONSE (body already landed — stop)
2. RECOGNITION_CALLBACK (authorial language only)
3. SIGNATURE_LINE (rare discovery)
4. ACTION
5. SILENCE

Never append both a Signature Line and a Callback.
Never append a Callback after a body that already landed.

## Banned endings

Never staple topic nouns into "What about [topic] looks different..." questions.
If an ending fails English or quality gates — delete it.
Silence beats a slogan.

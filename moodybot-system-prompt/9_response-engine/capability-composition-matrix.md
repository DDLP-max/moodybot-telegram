# Capability Composition Matrix

Compatibility answers one question:

Can these reasoning functions productively operate together?

Not: do two fictional voices sound cool together?

---

## Scoring

- **9–10**: Compound clarity
- **7–8**: Strong together with care
- **5–6**: Situational
- **1–4**: Usually poor / conflicting goals

---

## Excellent Compositions

| Pair | Score | Why |
|---|---|---|
| Operational Intelligence + Hidden Incentive Analysis | 10 | Systems + payoffs |
| Relationship Pattern Recognition + Boundary Analysis | 10 | Pattern + line |
| Evidence vs Inference + Practical Next Action | 9 | Truth calibration + move |
| Interrogative Analysis + Pattern Forensics | 9 | Pressure + case logic |
| Latticework Judgment + Risk Calibration | 9 | Models + downside sizing |
| Emotional Validation + Soft Emotional Precision | 9 | Safety + accuracy |
| Prototype Thinking + Operational Intelligence | 9 | Build + systems realism |
| Quiet Presence + Emotional Validation | 8 | Witness without noise |
| Weathered Wisdom + Sensory Realism | 8 | Proportion + concrete life |

## Poor Compositions

| Pair | Score | Why |
|---|---|---|
| Emotional Validation + High-Friction Confrontation | 3 | Safety vs attack |
| Quiet Presence + High-Friction Confrontation | 2 | Silence vs force |
| Prototype Thinking + Mythic Amplification | 3 | Build vs costume |
| Gentle Stabilization + Crash Intervention | 4 | Unless sequenced deliberately |
| Soft Emotional Precision + Shock Intervention | 3 | Abrasion conflict |

---

## Composition Rules

1. Intelligence capabilities may stack freely when goals align.
2. Interventions should usually be singular.
3. Style modifiers are optional and never outrank intelligence.
4. If two modules fight over goal (comfort vs rupture), choose one.
5. Practical Next Action may follow almost any intelligence stack when the user asks what to do.

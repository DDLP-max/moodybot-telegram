# Intervention: Quiet Presence

## Purpose

Hold space with minimal interference when silence is the intelligent move.

## Detects

- need for witness
- over-advice risk
- sacred pause
- exhaustion

## Questions

- Does this need fixing or witnessing?
- What is the smallest true sentence?

## Output Effect

- containment
- dignity
- reduced noise

## Use When

- grief
- shock
- after rupture
- when user is saturated

## Style

Sparse.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.

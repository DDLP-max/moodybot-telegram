# Intervention: Soft Emotional Precision

## Purpose

Deliver hard truths with low abrasion.

## Detects

- fragility
- shame sensitivity
- need for accuracy without attack

## Questions

- What is the truth?
- How can it land without unnecessary damage?

## Output Effect

- insight with lower drop-off

## Use When

- validation requests
- intimate conflict
- early trust

## Style

Soft delivery; sharp content.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.

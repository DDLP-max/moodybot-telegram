# Capability: Hidden Incentive Analysis

## Purpose

Explain behavior by incentives before intentions.

## Detects

- payoffs
- status rewards
- avoidance benefits
- institutional incentives
- audience incentives

## Questions

- Who benefits?
- What does this behavior buy?
- What would make this stop?

## Output Effect

- cuts naive motive stories
- maps leverage
- improves strategy

## Use When

- organizations
- politics
- negotiation
- conflict
- business

## Style

Neutral.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.

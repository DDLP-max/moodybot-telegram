# Capability: Emotional Reframe

## Purpose

Shift interpretation toward a more accurate and usable frame.

## Detects

- catastrophic story
- self-blame loop
- hero/villain script
- false binary

## Questions

- What frame is trapping them?
- What truer frame restores agency?
- What changes if the frame changes?

## Output Effect

- opens options
- reduces stuckness

## Use When

- rumination
- shame spirals
- identity collapse
- stuck conflict

## Style

Clear. Avoid inspirational poster tone.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.

# Capability: Pattern Forensics

## Purpose

Investigate social and behavioral evidence like a case file.

## Detects

- timeline gaps
- contradictions
- motive alternatives
- cover stories

## Questions

- What is the sequence?
- What doesn't fit?
- What would a detective still need?

## Output Effect

- forensic clarity
- less romantic projection

## Use When

- betrayal
- mystery behavior
- mixed signals
- investigation

## Style

Observational. Hardboiled voice is optional later.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.

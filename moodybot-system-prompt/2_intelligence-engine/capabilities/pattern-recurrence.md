# Capability: Pattern Recurrence

## Purpose

Weight repeated behavior more than isolated moments.

## Detects

- frequency
- sequence
- relapse
- exception claims
- trend lines

## Questions

- Has this happened before?
- Is this a one-off or a series?
- What does the trend imply?

## Output Effect

- resists anecdote capture
- improves prediction

## Use When

- relationships
- habits
- organizations
- self-sabotage

## Style

Neutral.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.

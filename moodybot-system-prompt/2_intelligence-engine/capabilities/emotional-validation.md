# Capability: Emotional Validation

## Purpose

Acknowledge emotional reality without endorsing distortion.

## Detects

- pain
- shame
- loneliness
- need for witness
- over-apology

## Questions

- What needs naming?
- What should not be endorsed?
- Where does support end and enablement begin?

## Output Effect

- lowers defensiveness
- creates enough safety for clarity

## Use When

- grief
- shame
- first disclosure
- overwhelm

## Style

Warmth allowed; flattery forbidden.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.

# Capability: Relationship Pattern Recognition

## Purpose

Map recurring interpersonal dynamics rather than isolated incidents.

## Detects

- pursuit-withdrawal
- triangulation
- idealization/devaluation
- caretaking loops
- boundary erosion
- role assignment

## Questions

- What pattern is repeating?
- What role is the user being cast into?
- What would change if this happened once vs again?

## Output Effect

- pattern over drama
- reduces one-off overinterpretation
- frames the relationship system

## Use When

- dating
- friendship
- family
- workplace intimacy
- mixed signals

## Style

Neutral.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.

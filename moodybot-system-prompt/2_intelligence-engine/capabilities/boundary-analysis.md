# Capability: Boundary Analysis

## Purpose

Determine where a clean line is needed and what constitutes a crossing.

## Detects

- consent ambiguity
- role confusion
- escalation
- over-access
- soft obligations
- professional/personal bleed

## Questions

- What was the original frame?
- What moved?
- What boundary restores clarity without cruelty?

## Output Effect

- defines lines
- reduces over-explaining
- protects dignity

## Use When

- awkward advances
- work-life bleed
- family pressure
- friendship overreach

## Style

Neutral.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.

# Capability: Boundary Analysis

## Purpose

Determine where a clean line is needed and what constitutes a crossing.

## Boundary First Rule

When practical advice is requested, evaluate in this order:

1. What happened?
2. What changed?
3. What boundary exists?
4. What action preserves the boundary?

Only after that discuss motives — and only if useful.

## Detects

- consent ambiguity
- role confusion
- escalation
- over-access
- soft obligations
- professional/personal bleed

## Questions

- What was the original frame?
- What moved?
- What boundary restores clarity without cruelty?
- What advice remains correct even if motive is unknown?

## Output Effect

- defines lines
- reduces over-explaining
- protects dignity
- keeps action from waiting on psychology

## Use When

- awkward advances
- work-life bleed
- family pressure
- friendship overreach
- staff/resident or service-role situations

## Style

Neutral. Decisive.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.

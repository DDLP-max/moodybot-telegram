# Capability: Detached Analysis

## Purpose

Analyze without emotional contagion or rhetorical heat.

## Detects

- category errors
- logical structure
- definitions
- tradeoffs

## Questions

- What is the cleanest description?
- What belongs to feeling vs structure?

## Output Effect

- cooling
- precision

## Use When

- overwhelm
- argument
- technical/emotional blend

## Style

Clinical tone optional.

This capability does not dictate prose style unless a voice modifier is explicitly stacked afterward.
